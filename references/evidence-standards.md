# 证据标准（Evidence Standards）

来源标注体系、三态交叉核验、中间数据 schema 与质量门禁。P5 成文前必读。

## 1. 来源标注体系

### 平台图标约定

| 图标 | 含义 |
|---|---|
| 📎 | 站外/官方/通用来源（官网、机构、媒体、知乎、公众号等） |
| 📺 | B站视频 |
| 📕 | 小红书笔记 |
| 🎵 | 抖音视频 |
| 📷 | 图片转写（OCR 自图片的二手呈现，标注原帖 + 图片页码） |
| 🆕 | 本轮检索新发现（相对既有结论） |

### 来源行格式

每条有来源的要点旁，紧跟一行灰色来源行：

```
<要点内容>
  📕 xiaohongshu.com/explore/<id> （作者《标题》，1675 赞）
```

规则：
- **URL 一律明文**（不用 markdown 链接包裹）：保证 Word/PDF/打印件都能复制核验；转换管线不支持超链接时天然兼容。
- 格式：`图标 + 域名/路径 + （作者《标题》，互动量）`；互动量（赞/藏/播放/赞同）必填——它是质量信号，也是回查线索。
- 二手转载：标注「转自」+ 原始出处线索；找不到原帖的写明「原帖未能定位，经 XX 转载」。
- 图片转写：`📷 图片转写：📕 <原帖链接> （P2-P5）`。
- 文首必须有**标注图例说明**，让读者知道图标含义。

### 三态交叉核验表

成文时附核验表（或按主题就近内嵌），格式：

| 结论 | 新证据 | 状态 | 处理 |
|---|---|---|---|
| 分析结论是最高分项 | 评审说明原文 + 3 篇经验帖 | ✅ 证实 | 维持，补充来源 |
| 样本量需千份 | 国二队实测 800–1000 份 | ⚖️ 修正 | 改为区间表述 |
| 博主「五维评分」说法 | 原帖站内已搜不到 | ⚠️ 未能复核 | 维持二手标注，不升格 |

- **证实**：≥2 独立来源或 1 个一手权威来源。
- **修正**：新的一手证据推翻旧表述 → 修正正文 + 保留修正轨迹。
- **未能复核**：如实标注，绝不为完整性而升格为已证实。

### 核验裁决规则（两个来源打架时）

三态核验只给了「状态」，冲突裁决按下述优先级链执行，**裁决理由必须写入核验表**：

1. **一手 > 二手**：官方原文/原始数据/当事人自述 > 转载、解读、二创（洗稿帖直接出局，见质量门禁 6）。
2. **官方 > 个人**：同为可读来源时，机构/官方账号 > 个人博主；平台官方公告 > 用户经验帖（平台规则类问题尤其如此）。
3. **新 > 旧**：平台策略、玩法、赛制等**随时间变化的知识**，晚发布的来源优先——但注意与「时间累积出的互动量」区分（老帖高赞不等于信息新）。
4. **无法裁决 → 并列呈现**：两条来源同级且矛盾，不擅自取舍——正文并列两种说法 + 核验表标注「⚠️ 冲突未裁决」，由读者依据来源自行判断。**宁可留着矛盾，不可制造虚假一致。**
5. **量级差异优先**：一手数据与二手说法差一个量级以上（如「千份样本」vs「百份实测」），优先怀疑笼统方，并将差异本身作为发现记录。

## 2. 采样方法论（偏差声明与终止条件）

> 漏斗「按互动量筛 top N」是本 skill 的核心动作，也是它最大的方法学软肋。本节是对该动作的强制约束，P3 漏斗取证与 P5 局限声明均须执行。

### 2.1 幸存者偏差声明

**问题**：按互动量筛选会系统性漏掉三类内容——① 刚发布还没积累互动的优质新帖；② 内容扎实但作者粉丝少的中低互动帖；③ 相反地，会放大高赞软文、买赞内容与「时间累积型老帖」（信息已过时但赞数还在涨）。

**强制对策**：

1. **时间加权采样**：漏斗结果除「互动量 top N」外，固定追加「最新发布 top N/2」（N 为深挖篇数），两类合并去重后深挖。发布时间从页面可见字段或详情页提取，落盘进 schema。
2. **双源支撑**：进入最终报告的关键结论，若其唯一支撑是高互动来源，必须再找一条非高互动路径（新帖 / 中低互动帖 / 静态一手源）交叉印证；找不到 → 结论标注「仅单一高互动来源支撑」。
3. **局限声明必含**：P5 报告的局限声明必须写明「本报告按互动量+时间加权采样，天然漏掉无互动的优质内容与被平台降权的内容」——让读者知道看见了什么，更知道没看见什么。

### 2.2 采样终止条件

防止无限爬取（礼貌访问）与过早收敛（漏信息），满足任一条即停止该平台采样：

1. **信息饱和**：连续 5 个新样本（深挖的帖子/视频）未带来任何新的信息类别（新观点/新数据/新反例）→ 停止。
2. **配额用尽**：单平台深挖篇数达上限（默认 top 10 + 新帖 5；特别重大的主题经判断可放宽，但须在报告中说明放宽理由）。
3. **矛盾扩采样**（唯一允许突破配额的情况）：关键问题上证据出现 2.1/裁决规则无法消化的矛盾 → 追加一轮定向采样（最多 5 篇，定向搜矛盾点的关键词），仍无法裁决 → 按「并列呈现」收尾，不再扩。

## 3. 中间数据 Schema

> **通用字段约定（v0.2.0 起）**：
> - `platform`：`bili | xhs | douyin | zhihu | web`——跨平台汇合分析时的分组依据，禁止靠文件名推断；
> - `crawledAt`：ISO 8601 抓取时间戳（如 `2026-10-21T18:30:00+08:00`）——**每条互动型数据必填**；
> - `likeLabel`：`like | view | agree`——声明 `like` 字段的语义（赞/播放/赞同），禁止消费方猜测。
>
> **为什么 `crawledAt` 必填**：互动量是「活数据」，每时每刻都在变。今天记 1675 赞，用户下周核验可能已是 3000——单靠互动量当核查锚点会漂移失准；「互动量 + 抓取时间戳」组合才是稳定锚点（核对时按时间差预估合理涨幅）。

### 漏斗搜索结果（每平台一份 `*_search_results.json`）

```json
{
  "platform": "xhs",
  "crawledAt": "2026-10-21T18:30:00+08:00",
  "keywords": {
    "<关键词>": [
      {
        "title": "标题",
        "author": "作者/UP主",
        "like": 1675,            // 互动量原始值，语义由 likeLabel 声明
        "likeLabel": "like",     // xhs/bili=like；douyin=like(获赞)；zhihu=agree
        "extra": {"collect": 0, "commentCount": 0},  // 可选
        "href": "/search_result/<id>?xsec_token=...",   // 完整原样保留！
        "keyword": "来源关键词"
      }
    ]
  }
}
```

### 深挖详情（`*_details.json`）

```json
{
  "platform": "xhs",
  "crawledAt": "2026-10-21T19:05:00+08:00",
  "title": "...", "author": "...", "url": "完整带token链接",
  "desc": "正文全文", "like": 0, "likeLabel": "like",
  "collect": 0, "commentCount": 0,
  "comments": [ {"author": "...", "content": "...", "likes": 0} ]
}
```

### 图片列表（`*_imglist.json`）

```json
[ {"src": "https://...", "dataSrc": "", "cls": "...", "w": 1080} ]
```

筛选规则：CDN 域（如 sns-webpic）+ 宽度 ≥1080 优先 + URL 路径特征（如 notes_pre_post）；排除头像/图标/推荐流封面。

### 图片转写稿（`图片经验帖OCR提取纪要.md`）

按原帖分节：原帖信息（标题/作者/赞藏/链接）→ 逐页转写（`P1`、`P2`… 对应原图编号）→ 洗稿检测结论。

## 4. 质量门禁

1. **落盘即回读**：每个 JSON 写完回读校验条数与关键字段（硬规则 3）。
2. **API 回验**：可公开核验的数据（B站视频信息等）必须经官方 API 回验后才写入结论。
3. **互动量 + 时间戳必录**：没有互动量的来源行不合格；互动量落盘时必须带 `crawledAt` 抓取时间——两者组合才是可回查的稳定锚点（硬规则：活数据不定锚）。
4. **诚实标注**：登录墙、折叠、付费墙、搜不到，全部如实记录；降级来源（转载/二手）不与一手混排。
5. **成品回读**：最终交付物在成品内部验证关键词在位（如 docx 的 document.xml），并抽样回查 5–10 条链接。
6. **洗稿检测**：高度雷同的二创内容不作为独立来源计数，避免来源统计虚高。
7. **采样纪律**：漏斗采样执行第 2 节全部对策（时间加权采样、双源支撑、终止条件）；深挖样本含「最新发布」组。
